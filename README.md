# Sales Table SQL Analysis (Mini Project)

## 📌 Project Overview
This mini project focuses on analyzing sales data using SQL. The goal of this project is to extract meaningful business insights from a sales table using structured queries.

## 🛠️ Concepts Used
- Aggregate Functions (SUM, MAX)
- GROUP BY & HAVING
- Subqueries
- Date Functions (YEAR, MONTH)
- Sorting and Filtering Data

## 📊 Analysis Performed
- Total revenue calculation
- Category-wise revenue analysis
- Monthly revenue trend using order date
- Top revenue-generating category
- Revenue comparison using subqueries

## 📁 Tools Used
- MySQL
- MySQL Workbench

## 🎯 Learning Outcome
This project helped me strengthen my understanding of SQL aggregation, grouping logic, subqueries, and real-world sales data analysis.
